# CATER data helper functions

This is some code to work with data collected by the CATER project.

See:

*Haalck, L, Mangan, M, Wystrach, A, Clement, L, Webb, B & Risse, B 2023,
'Cater: Combined Animal Tracking & Environment Reconstruction',
Science Advances, vol. 9, no. 16, eadg2094, pp. 1-13.* [DOI](https://doi.org/10.1126/sciadv.adg2094)

It is used in [antpov](https://github.com/BrainBeatsBrawn/antpov)
